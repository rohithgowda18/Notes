# ☕ Core Java — Programming & Streams

This folder covers Core Java fundamentals, memory management, and modern functional programming with the Java Streams API.

---

## 📑 Contents

- 📄 **[java Programming.pdf](./java%20Programming.pdf)**: Complete Core Java guide covering syntax, JVM architecture (Class Loader, Metaspace, Heap, Stack, PC Register, Native Method Stack), JIT compiler, Garbage Collection, Multithreading & Synchronization, Exception Handling, and the Java Collections Framework (`ArrayList`, `LinkedList`, `HashMap`, `TreeMap`, `ConcurrentHashMap`).
- 📝 **[Java Streams.md](./Java%20Streams.md)**: In-depth tutorial and cheat sheet for Java 8+ Streams API, Functional Interfaces (`Predicate<T>`, `Consumer<T>`, `Supplier<T>`, `Function<T, R>`), intermediate operations (`map`, `filter`, `flatMap`, `sorted`, `distinct`), terminal operations (`collect`, `forEach`, `reduce`, `count`, `min`, `max`), and parallel streams.
