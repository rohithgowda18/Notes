## 🎯 Core Interview Checklist

- [ ] **4 Pillars of OOP**:
  - **Encapsulation**: Data hiding, getters/setters, access modifiers (`private`, `protected`, `public`, `default`).
  - **Abstraction**: Abstract classes vs Interfaces (Default & static methods in Java 8+).
  - **Inheritance**: Single, Multilevel, Hierarchical, and Diamond Problem resolution.
  - **Polymorphism**: Method Overloading (Compile-time) vs Method Overriding (Run-time), Virtual tables.
- [ ] **SOLID Principles**:
  - **S**: Single Responsibility Principle
  - **O**: Open/Closed Principle
  - **L**: Liskov Substitution Principle
  - **I**: Interface Segregation Principle
  - **D**: Dependency Inversion Principle
- [ ] **Key Design Patterns**:
  - **Singleton**: Thread-safe implementation, Double-Checked Locking, Enum Singleton.
  - **Factory & Abstract Factory**: Decoupling object creation from business logic.
  - **Builder**: Constructing complex objects step-by-step.
  - **Observer & Strategy**: Event-driven decoupled architectures.
