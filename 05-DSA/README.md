## 🎯 High-Yield DSA Patterns Checklist

1. **Arrays & Two Pointers**: Sliding Window, Two Pointers (Opposite/Same direction), Kadane's Algorithm, Prefix Sums.
2. **Linked Lists**: Fast & Slow Pointers (Floyd's Cycle Detection), Reversing a Linked List, Merge K Sorted Lists.
3. **Stacks & Queues**: Monotonic Stack (Next Greater Element, Largest Rectangle in Histogram), Min Stack, BFS queue traversal.
4. **Trees & Binary Search Trees**: Inorder/Preorder/Postorder traversals (Recursive & Iterative), Lowest Common Ancestor (LCA), Diameter of Tree, Valid BST.
5. **Heaps & Priority Queues**: Top K Frequent Elements, Median from Data Stream, Kth Largest Element.
6. **Graphs**: BFS, DFS, Dijkstra's Shortest Path, Topological Sort (Kahn's Algorithm), Union-Find (Disjoint Set Union - DSU), Bellman-Ford.
7. **Dynamic Programming**: 0/1 Knapsack, Longest Common Subsequence (LCS), Longest Increasing Subsequence (LIS), Matrix DP, State DP.
8. **Sorting & Searching**: Binary Search on Answer / Search Space, QuickSort partition, MergeSort.
